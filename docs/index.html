Features

流式输出

上下文感知

结合页面标题与前段译文构造滑动窗口，长文的代词指代、术语口径前后一致，像人读完全文再下笔。

质量自检

译后自动校验数字、URL、邮箱、占位符与代码 token 是否保真，缺失时追加指令校正重试并标记提示。

FAQ

常见问题

好翻真的完全免费吗？
扩展本身 MIT 开源、永久免费、无任何功能限制。翻译消耗由你自己的服务商账户承担（如 DeepSeek 按量计费）；不想花钱可以选「Google 翻译」免 Key 通道体验，或用 Ollama 本地模型实现零成本且断网可用（指不再访问云端 AI）。
我的浏览内容和 API Key 安全吗？
Key 只存在你浏览器的 storage.local，按服务商隔离，仅通过 Authorization 头直发给所选服务商——不经过任何第三方服务器。待译文本用「数据边界」包裹防提示注入；译文以 textContent 注入 Shadow DOM，无 XSS 面；扩展自身零遥测。以上每一条都能在源码里找到对应实现。
和「沉浸式翻译」这类产品有什么区别？
核心差异在架构：多数产品把你的网页内容先发到厂商服务器再转发翻译，Key 也存在云端，免费额度有限且闭源；好翻是直连架构 + 完整开源——你配置谁就直连谁，Key 不出本机，源码可审计，无额度限制。双语对照的阅读体验我们同样打磨得非常细致。
会大量消耗 Token 吗？
好翻为此设计了五层省钱机制：句子级缓存（微变只译变化句）、30 天 LRU 整段缓存、术语库命中零请求、已是目标语言本地跳过、动态内容 8 秒冷却 + 数字就地更新。还有「手动模式」整页不自动翻，点哪译哪。首次翻译后重复阅读几乎零消耗。
支持哪些语言和网站？
18 种主流语言互译，源语言支持自动检测；任意普通网页均可翻译（含 SPA 动态内容、无限滚动）。PDF 与浏览器内部页暂不支持，可在弹窗中使用文本翻译替代。
为什么安装后没有商店版那样自动更新？
当前为开发者模式加载的未签名包，浏览器不会自动更新——这是平台限制。请关注 Releases 页面获取新版本；商店上架正在推进中，上架后将支持自动更新。
